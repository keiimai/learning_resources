# Learning Resources

統計学・疫学・機械学習を学ぶための書籍をまとめたWebサイトです。

**サイトはこちら：[https://keiimai.github.io/learning_resources/](https://keiimai.github.io/learning_resources/)**

## 掲載しているページ
- **統計学**：医療統計の入門書から統計学の教科書まで。「特定の言語を使わない本」「R を使う本」「Stata を使う本」に分けて並べています。
- **疫学**：疫学・臨床研究のデザイン・因果推論の本。「入門編」「発展編」に分けて並べています。
- **機械学習**：Python による実装、数学の基礎、機械学習の理論、深層学習の本。

## ご利用にあたって
- 各書籍のリンクは、主に出版社の書籍ページにつながります。
- 邦訳のある洋書は、原著と邦訳を並べて載せています。
- 書籍の情報は掲載した時点のものです。最新の版や価格は、リンク先でご確認ください。
