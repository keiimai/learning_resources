# Learning Resources

統計学・疫学・機械学習を学ぶための書籍をまとめたサイトです。

## 掲載しているページ
- [統計学](statistics_books.md)：医療統計の入門書から統計学の教科書まで。「特定の言語を使わない本」「R を使う本」「Stata を使う本」に分けて並べています。
- [疫学](epidemiology_books.md)：疫学・臨床研究のデザイン・因果推論の本。「入門編」「発展編」に分けて並べています。
- [機械学習](machine_learning_books.md)：機械学習とデータ分析の本。「Python による実装」「数学の基礎」「機械学習の理論」「深層学習」に分けて並べています。

## ご利用にあたって
- 書名をクリックすると、主に出版社の書籍ページが開きます。
- 邦訳のある洋書は、原著と邦訳を並べて載せています。
- 書籍の情報は掲載した時点のものです。最新の版や価格は、リンク先でご確認ください。
